# sistema_Festa-Cia_Trabalho_Final_POO
Sistema desenvolvido com o propósito de auxiliar e modernizar o gerenciamento de clientes da dona Lourdes (Minha vó). Este também é meu projeto do 4º Bimestre de Programação Orientada à Objetos(POO)

Equipe:
 - Jairo Pimenta de Lima Neto
 - Raphael Junior Camargo Rodrigues

Objetivo:
O sistema tem como principal função modernizar o método de gerenciamento dos clientes da Festa e Cia, vizando perda mínima de dados e melhor gestão.
O sistema deve ser simples 
O sistema deve ser projetado para dispositivos móveis

Desafios:
Fazer um sistema acessível para idosos, desenvolver o projeto para dispositivos móveis 

Funcionalidades:
o sistema irá cadastar o cliente junto com seu pedido
haverá um sistema de alerta avisando da data de entrega da locação
fazer o inventário completo dos itens disponíveis para locação
o sistema irá verificar o pedido do cliente, analizar se está disponivel e atualizar a quantidade disponivel após a locação
